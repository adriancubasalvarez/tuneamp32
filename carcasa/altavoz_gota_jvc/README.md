# JVC teardrop speaker / Altavoz de gota JVC

![Vista](vista.png)

**English.** Printable teardrop speaker pod for the JVC CS-J520X, designed by Adrián (@Adriancubas1980). Version 2. The TuneAmp32 factory settings were measured with the JVC pods (see `medidas/resultados/`).

**Español.** Cápsula imprimible en forma de gota para el JVC CS-J520X, diseñada por Adrián (@Adriancubas1980). Versión 2. Los valores de fábrica de TuneAmp32 se midieron con las cápsulas JVC (ver `medidas/resultados/`).
