Instala TuneAmp32 en tu ESP32

Desde Chrome o Edge en un ordenador, sin instalar nada más. Sirve para un ESP32 clásico (ESP32-WROOM-32, DevKit de 30 pines) con el DAC PCM5102A.

Este navegador no puede instalar: usa Chrome o Edge en un ordenador. La instalación necesita una conexión segura (https). Versión …

Pasos

  1. Conecta el ESP32 al ordenador con un cable USB de datos.
  2. Cierra cualquier otra página o programa que use el puerto (el asistente, el panel o un monitor serie).
  3. Pulsa Instalar en el ESP32 y elige el puerto (suele llamarse CH340 o CP210x).
  4. Si pregunta si quieres borrar el dispositivo, responde que no: así conservas la corrección guardada. Bórralo solo si quieres empezar de cero.
  5. Espera a que termine (menos de un minuto) y abre el asistente.

Después de instalar

  • En el Bluetooth del móvil aparece TuneAmp32.
  • Si es la primera vez, sale de fábrica sin corrección: empieza con el volumen bajo.
  • Para afinarlo a tus altavoces, sigue el asistente.

Install TuneAmp32 on your ESP32

From Chrome or Edge on a computer, with nothing else to install. For a classic ESP32 (ESP32-WROOM-32, 30-pin DevKit) with the PCM5102A DAC.

This browser cannot install: use Chrome or Edge on a computer. Installing needs a secure connection (https). Version …

Steps

  1. Connect the ESP32 to the computer with a USB data cable.
  2. Close any other page or program using the port (the assistant, the panel or a serial monitor).
  3. Press Install on the ESP32 and choose the port (usually named CH340 or CP210x).
  4. If it asks whether to erase the device, answer no: that keeps your saved correction. Erase only to start from scratch.
  5. Wait until it finishes (under a minute) and open the assistant.

After installing

  • TuneAmp32 appears in your phone's Bluetooth.
  • The first time, it comes without correction: start with the volume low.
  • To tune it to your speakers, follow the assistant.
